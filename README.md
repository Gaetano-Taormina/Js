## Come eseguire i progetti

1. Entra nella cartella di un esercizio (es. `cd dom/01-esercizio`)
2. Apri il file `index.html` direttamente nel browser web. Per visualizzare eventuali modifiche al codice, sarà sufficiente aggiornare la pagina manualmente (ad es. premendo `F5` o `Cmd+R` su macOS). In alternativa, per abilitare l'aggiornamento automatico (hot-reloading), si consiglia l'utilizzo di estensioni come **Live Server** per VS Code.

## How to Run Locally

1. Navigate to any exercise folder (e.g., `cd dom/01-esercizio`)
2. Open the `index.html` file directly in your web browser. To view any subsequent code changes, manually refresh the page (e.g., by pressing `F5` or `Cmd+R` on macOS). Alternatively, for an automated hot-reloading experience, we recommend using extensions such as **Live Server** for VS Code.
